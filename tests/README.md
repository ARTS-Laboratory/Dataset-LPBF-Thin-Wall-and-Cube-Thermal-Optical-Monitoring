# Tests

Contains individual experimental tests organized into folders (`test_01/`, `test_02/`, `test_03/`, etc.). Each test is self-contained, including the build files, controller code, experimental setup, data, and processing scripts needed for that experiment. The contents and configurations may vary between tests as needed.

## Test 01

Conducted on November XX, 2026, this initial thermal and optical monitoring test was performed during an LPBF build to acquire a baseline dataset. The test included continuous optical and thermal image capture, followed by post-processing and selection of images to produce a curated dataset for future analysis.
